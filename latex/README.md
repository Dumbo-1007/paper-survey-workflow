# LaTeX 阅读报告模板

## 文件

| 文件 | 说明 |
| --- | --- |
| `document.tex` | 报告模板，固定 8 节骨架，每节都写了「这一段该写什么」的注释 |
| `pic/` | 存放报告用到的截图/自制图，`document.tex` 里以 `pic/文件名`（不带扩展名）引用 |

## 编译

需要 TeX 发行版（TeX Live / MiKTeX）并提供 `ctex` 宏包与中文字体。

```bash
# 编译两次：第一次生成交叉引用信息，第二次才正确
xelatex document.tex
xelatex document.tex
```

编译产物 `document.pdf` 即「阅读报告」，按下面的命名规范归档。

> `cleveref` 必须放在 `hyperref` 之后，否则 `\cref` 会报错。
> 中文文档统一用 `xelatex`，不要用 `pdflatex`。

## 约定

1. **节标题不要改名。** 固定 8 节，归档脚本靠节标题定位内容（见 `docs/06-自动化与脚本使用.md`）。
2. **图片统一放 `pic/`**，命名用 `screenshot001`、`screenshot002`… 递增，方便回看顺序。
3. **每个关键公式后面必须写符号含义与设计动机**，不要只贴公式。
4. **报告正文里不要写个人敏感信息**（学号、导师姓名、联系方式、本机绝对路径），因为报告会被归档、可能被分享。

## 报告文件命名规范（建议）

```
reports/
├── 01-1/                  # 第 1 次调研 · 第 1 篇
│   ├── document.tex       # 报告源文件
│   ├── document.pdf       # 阅读报告（编译产物）
│   ├── 论文原文.pdf        # 从出版商/数据库下载的原文
│   └── pic/
├── 01-2/
└── ...
```

一份报告 = 一个文件夹。命名 `批次-序号`，批次与序号和元数据表（`tools/metadata.example.csv`）一一对应，归档脚本据此自动配对。
