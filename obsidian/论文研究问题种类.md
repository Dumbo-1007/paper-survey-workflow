# 论文研究问题种类

全库论文按**研究问题**的分类总表。分类以嵌套标签 `种类/…`、`挑战/…`、`技术/…`
落到每张 [[调研汇报论文库|论文卡片]] 上，点击标签即可看到同类论文。

> [!note] 字段分工（关键词只存一处）
> - **关键词只写在 tags**（`种类/…`、`挑战/…`、`技术/…`），不再重复进属性——单一来源，不会写飘
> - **属性只放标量字段**：论文题目、期刊会议、年份、文献类型、分区、影响因子、研究内容、批次、报告时间
> - 词表见 `obsidian/标签词表.md`，新增词先改词表再加标签

> [!tip] 怎么一键看同类论文
> 点击任意标签即弹出全库同关键词的论文；也可在搜索框输入 `tag:#挑战/多模态融合`，
> 或用本页下方的 Dataview（查询读的是 `file.etags`，与标签同源）。

## 四、交叉视图（Dataview）

### 全部卡片（按批次）

```dataview
TABLE filter(file.etags, (t) => startswith(t, "#种类/")) AS 种类, filter(file.etags, (t) => startswith(t, "#挑战/")) AS 挑战, 分区 AS 分区, 影响因子 AS IF, 年份 AS 年份
FROM "论文卡片"
SORT 批次 ASC, file.name ASC
```

### 只看 1 区期刊论文

```dataview
TABLE 期刊会议 AS 期刊, 影响因子 AS IF, filter(file.etags, (t) => startswith(t, "#种类/")) AS 种类
FROM "论文卡片"
WHERE 分区 = "1区"
SORT 影响因子 DESC
```
