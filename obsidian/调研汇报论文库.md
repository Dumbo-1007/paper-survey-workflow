# 调研汇报论文库

把每次调研汇报的论文沉淀成卡片：一篇论文一张卡片，卡片之间靠**三轴标签**互相指向，
PDF 原文与阅读报告放在附件目录。

- 分类总表：[[论文研究问题种类]]（任务维度 + 方法挑战维度 + 技术维度）
- 元数据表：`tools/metadata.csv`（分区、影响因子、报告时间、标签，全库唯一来源）
- LaTeX 报告源：`reports/批次-序号/`

> [!tip] 汇总
> 共 N 篇；1 区期刊 N 篇、2 区期刊 N 篇、会议 N 篇。
