# 示例文件

这些文件是从一份真实的调研汇报记录里导出的（30 篇论文，第 1–15 次调研），
用来展示「范式跑起来之后长什么样」。**里面的论文都是公开发表的文献，不含任何个人信息。**

| 文件 | 说明 |
| --- | --- |
| `卡片示例-EviPrompt.md` | 一张完整的论文卡片：属性 + 三轴标签 + 五节正文 + 同类论文查询 + 附件链接 |
| `阅读报告示例-EviPrompt.tex` | 上面那张卡片对应的 LaTeX 报告源（8 节模板填满后的样子），可直接 `xelatex` 编译 |
| `元数据示例-30篇.csv` | 30 篇论文的元数据表，含三轴标签，可直接喂给 `tools/build_cards.py` |
| `分类表示例.md` | 由上面那份元数据表生成的分类总表（任务 / 挑战 / 技术三张清单 + Dataview 视图） |
| `总索引示例.md` | 由上面那份元数据表生成的总索引（按批次分组） |

## 怎么用这些示例

```bash
# 只重算分类表与总索引，把结果写到 ./_build 下对照着看
python3 tools/build_cards.py \
    --meta examples/元数据示例-30篇.csv \
    --vault ./_build \
    --cards-dir 论文卡片 --index-dir . \
    --classify-only
```

输出应与 `分类表示例.md`、`总索引示例.md` 一致（示例里的 `报告时间` 列已清空，故索引标题不带日期）。

## 两点说明

1. **分类表里的 `[[…]]` 链接会指向不存在的卡片**——本仓库只带 1 张示例卡片，
   其余 29 篇的卡片没有随仓库分发。这不影响阅读表格本身。
2. **报告示例里的图片已被注释掉**。原报告引用了论文里的截图（`pic/screenshot00x.png`），
   出于版权考虑不随仓库分发，所以 `\includegraphics` 行被注释，示例可以直接编译通过。
   自己写报告时按 `latex/README.md` 的约定放图即可。
