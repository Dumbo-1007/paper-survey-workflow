# Obsidian 库搭建

本套归档依赖 Obsidian（免费）与 **Dataview** 社区插件。不需要其他插件。

## 一、目录结构

把你已有的知识库随便找个子目录挂进去即可，本范式只要求下列相对关系：

```
<你的 Obsidian 仓库>/
├── 30-研究论文/                        ← 可改名，只要前后一致
│   └── 调研汇报论文库/
│       ├── 调研汇报论文库.md            ← 总索引（MOC），脚本生成
│       ├── 论文研究问题种类.md          ← 分类总表，脚本生成
│       └── 论文卡片/                    ← 一篇论文一张卡片，脚本生成
│           ├── 03-1 SAM免训练证据提示-EviPrompt.md
│           └── ...
├── 90-附件/                            ← 可改名
│   └── 调研汇报论文库/
│       ├── 03-1-论文原文.pdf
│       └── 03-1-阅读报告.pdf
└── .obsidian/
```

文件夹名和层级都可以改，改完把新路径传给脚本：

```bash
python3 tools/build_cards.py \
    --meta reports/metadata.csv \
    --src  reports \
    --vault "/你的Obsidian仓库" \
    --cards-dir "30-研究论文/调研汇报论文库/论文卡片" \
    --index-dir "30-研究论文/调研汇报论文库" \
    --attach-dir "90-附件/调研汇报论文库"
```

> [!important] `--cards-dir` 必须与卡片里 Dataview 查询的 `FROM` 一致
> 脚本会用 `--cards-dir` 自动生成卡片里的 `FROM "..."`，所以只要路径对，查询就能跑。

## 二、安装 Dataview

1. 设置 → 第三方插件 → 关闭「安全模式」→ 浏览社区插件 → 搜索 **Dataview** → 安装并启用。
2. 「设置 → Dataview」里确认 **Enable JavaScript Queries** 无所谓，**Enable Inline Queries** 可按需；
   本范式的查询都是 `dataview`（DQL）代码块，默认即可。
3. 回到任意卡片，看到「同类论文」表格出现内容即安装成功。

排查：如果显示 `Dataview: Unrecognized query language`，说明插件没启用；
如果显示空表格，检查 `FROM` 里的目录名是否和实际一致。

## 三、模板怎么用

`obsidian/templates/` 下有：

| 文件 | 用途 |
| --- | --- |
| `论文卡片模板.md` | 手动新建卡片时用（正常流程由脚本生成，这份用于理解字段含义） |
| `调研批次索引模板.md` | 每次汇报建一页，写提纲与沉淀 |

用法：把这两个文件复制进你库里的模板目录（通常 `.obsidian/templates/`），
用 **Templater / 核心模板插件** 的「插入模板」功能调用。

> 脚本生成卡片时不会覆盖你手写的「批次索引」，两者互不干扰。

## 四、三种检索入口

### 1. 分类总表（点开就有）

`论文研究问题种类.md` 按三轴把全部论文排成三张清单，每节都写着「N 篇」。
「N 篇 = 1」的标签就是潜在的空白方向，直接点进去看。

### 2. 标签面板（最快）

右侧标签面板 → 展开 `种类/` `挑战/` `技术/` → 点任意标签，全库同类论文并列。
等价的手写检索式：

```text
tag:#挑战/不确定性建模              单标签
tag:#挑战/不确定性建模 tag:#种类/医学图像分割    多标签取交集
tag:#技术/图神经网络与超图建模 -tag:#种类/医学图像分割   取差集：还有哪些任务没人用图模型
```

**取差集的检索式是找选题空白最快的方法。**

### 3. Dataview 表格（可排序、可组合）

放在分类表末尾的几条查询：

```dataview
TABLE 分区 AS 分区, 影响因子 AS IF, 年份 AS 年份
FROM "论文卡片"
WHERE 分区 = "1区"
SORT 影响因子 DESC
```

改 `WHERE` 就能问新问题，例如：

```dataview
TABLE 期刊会议, 年份, 研究内容
FROM "论文卡片"
WHERE 批次 >= 10 AND 分区 = "1区"
SORT 年份 DESC
```

> Dataview 的 `WHERE` 里直接用属性名（`分区`、`年份`）即可，不需要 `file.` 前缀；
> `分区`、`年份` 这些属性来自卡片 frontmatter，**想按标签筛就用 `file.etags` 或 `tag:` 检索式**。
> 也可以把标签先投影成列再看：`TABLE filter(file.etags, (t) => startswith(t, "#技术/")) AS 技术`。

## 五、卡片正文里的数学

归档脚本会把 LaTeX 公式转成 Obsidian 可渲染的形式（`$…$` / `$$…$$`）。
渲染规则与注意事项见 `docs/05-LaTeX转Obsidian规范.md`——**尤其注意数学环境里不能有中文**。

## 六、备份与同步

- 卡片是**生成物**，真正的源头是 LaTeX 报告 + 元数据表。所以：**报告和元数据表一定要进 Git**，
  卡片可以一起提交（方便阅读），丢了也能一键重建。
- Obsidian 自带的「文件恢复」只保最近几次，别当备份用。
- 多设备同步时 `.obsidian/workspace*.json` 不要同步（`.gitignore` 已忽略），
  否则会互相覆盖窗口布局。

## 七、与既有知识库共存

- 卡片的 `tags` 里除了三轴标签，还有 `调研汇报论文库` 和 `研究论文/论文卡片` 两个**库标签**，
  用来在全局标签面板里把这一批论文和其他笔记区分开。
- 如果你已有自己的标签体系，把三轴标签嵌进去即可：改 `tools/taxonomy.csv` 的 `axis` 取值、
  `obsidian/标签词表.md` 的说明表，以及 `tools/build_cards.py` 里出现 `种类/挑战/技术` 的几处常量
  （`read_taxonomy`、`check_tags`、`build_card`、`build_taxonomy`），其余流程不变。
- 只换研究方向（不换标签体系）时，**只需要替换 `tools/taxonomy.csv` 与 `obsidian/标签词表.md` 两份词表**，
  脚本和模板都不用动。
