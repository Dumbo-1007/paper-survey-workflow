# 自动化脚本使用说明

脚本：`tools/build_cards.py`。只依赖 Python 3 标准库（不需要 pandas），Python 3.7+ 均可。

## 一、输入的三样东西

### 1. 元数据表（CSV）

从 `tools/metadata.example.csv` 复制一份，用 Excel / WPS 编辑并另存为 **CSV UTF-8**。
列名固定（顺序可换）：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| `批次` | ✔ | 第几次调研，整数，如 `3` |
| `序号` | ✔ | 该批次的第几篇，整数，如 `1` |
| `短标题` | ✔ | 卡片标题与文件名主体，如 `SAM免训练证据提示-EviPrompt` |
| `研究内容` | | 一句话，用于表格展示（不是标签） |
| `论文题目` | ✔ | 完整题目 |
| `期刊会议` | ✔ | 期刊/会议全称 |
| `年份` | ✔ | 发表年份 |
| `文献类型` | | `期刊` / `会议`；留空则按 `分区` 是否含 `CCF` 自动判定 |
| `分区` | ✔ | `1区` / `2区` / `CCF A` …（字段含义可自定义，保持一致即可） |
| `影响因子` | | 期刊填，会议留空 |
| `报告时间` | | `2026-01-28` 格式，用于索引分组标题 |
| `种类` | ✔ | 标签，多个用 `;` 分隔，如 `医学图像分割` |
| `挑战` | ✔ | 同上，如 `不确定性建模;通用基础模型与上下文学习` |
| `技术` | ✔ | 同上 |

> 标签列里**只写标签名，不写 `种类/` 前缀**，脚本会自动补前缀。

### 2. LaTeX 报告目录

默认布局（可用 `--tex-pattern` 改成别的）：

```
reports/
├── 03-1/
│   ├── document.tex        ← 必需（名字由 --tex-pattern 决定）
│   ├── 论文原文.pdf         ← 可选（--pdf-original）
│   ├── 阅读报告.pdf         ← 可选（--pdf-report）
│   └── pic/
└── 03-2/
```

`document.tex` 里必须包含模板规定的 8 个 `\section`，否则卡片对应小节会是「（待补充）」。

### 3. 词表

`tools/taxonomy.csv`（两列 `axis,tag`）：既决定分类表里各标签的**排列顺序**，
也用来**校验标签**。出现词表里没有的标签时脚本会警告并把它排在对应轴的末尾，
不会中断执行——这是为了让你能先跑起来，再回头补词表。

`tools/math_replacements.csv`（两列 `原文,替换为`，可选）：
公式内中文等内容的批量替换补丁，见 `docs/05-LaTeX转Obsidian规范.md`。

## 二、命令

```bash
# 全量归档（读报告 + 复制 PDF + 生成卡片/分类表/总索引）
python3 tools/build_cards.py \
    --meta reports/metadata.csv \
    --src  reports \
    --vault "/你的Obsidian仓库" \
    --cards-dir "30-研究论文/调研汇报论文库/论文卡片" \
    --index-dir "30-研究论文/调研汇报论文库" \
    --attach-dir "90-附件/调研汇报论文库"

# 只重算分类表与总索引（改了标签/新增一行元数据，不碰 LaTeX，秒级）
python3 tools/build_cards.py --meta reports/metadata.csv --vault "/你的Obsidian仓库" \
    --cards-dir "30-研究论文/调研汇报论文库/论文卡片" \
    --index-dir "30-研究论文/调研汇报论文库" --classify-only

# 用仓库自带示例试跑（不需要 LaTeX，直接在 ./_build 下看结果）
python3 tools/build_cards.py --meta tools/metadata.example.csv --vault ./_build \
    --cards-dir 论文卡片 --index-dir . --classify-only
```

### 参数表

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--meta` | 必填 | 元数据 CSV |
| `--vault` | 必填 | Obsidian 仓库根目录 |
| `--src` | `reports` | LaTeX 报告根目录 |
| `--cards-dir` | `论文卡片` | 卡片目录（相对 `--vault`）；同时作为卡片里 Dataview 的 `FROM` 值 |
| `--index-dir` | `.` | 分类表与总索引的输出目录（相对 `--vault`） |
| `--attach-dir` | `附件` | PDF 附件目录（相对 `--vault`） |
| `--taxonomy` | `tools/taxonomy.csv` | 词表 CSV |
| `--math-fix` | `tools/math_replacements.csv` | 公式替换表（可缺省） |
| `--tex-pattern` | `{b:02d}-{i}/document.tex` | 报告路径模板，`{b}` 批次 `{i}` 序号 |
| `--pdf-original` | `{b:02d}-{i}/论文原文.pdf` | 原文 PDF 路径模板；传空字符串则不复制 |
| `--pdf-report` | `{b:02d}-{i}/阅读报告.pdf` | 报告 PDF 路径模板 |
| `--attach-pattern` | `{b:02d}-{i}-{kind}.pdf` | 附件重命名模板，`{kind}` = `论文原文` / `阅读报告` |
| `--index-names` | `调研汇报论文库,论文研究问题种类` | 总索引名,分类表名 |
| `--batch-label` | `第 {n} 次调研` | 索引里的批次标题模板 |
| `--classify-only` | 关 | 只重算分类表与总索引 |
| `--no-pdf` | 关 | 不复制 PDF |

## 三、脚本每一步做了什么

1. **读元数据**：解析 CSV，按 `批次, 序号` 排序，拆分三轴标签。
2. **校验标签**：与 `taxonomy.csv` 比对，输出警告（不中断）。
3. **抽取正文**：按 `\section` 切分 `document.tex`，按 `CARD_SECTIONS` 映射合并成
   5 个卡片小节；`阅读文献来源` 的第一行作为「文献来源」。
4. **清洗 LaTeX**（`latex_to_md`）：
   保护公式 → 转换列表 → 丢弃图表环境 → 标题转粗体 → 恢复公式 →
   统一编号写法 → `aligned` 转 `displaylines` → 应用替换表 → 独立公式前后补空行。
5. **检查公式中文**：发现数学环境里有中文就报警，并打印前 5 处片段。
6. **复制 PDF**：按模板命名复制到附件目录（原文与报告分开命名，避免重名）。
7. **写卡片**：frontmatter（属性 + 三轴标签）+ 五节正文 + 同类论文查询 + 附件链接。
8. **写分类表与总索引**：按词表顺序生成三张清单（每节带篇数）+ Dataview 交叉视图。

> 脚本是**幂等**的：同一份输入重跑多次，输出完全一致。
> 卡片、分类表、总索引都是**生成物**，不要在 Obsidian 里手改。

## 四、典型使用场景

### 新增一次调研

1. 建目录 `reports/16-1/`、`reports/16-2/`，写报告，编出 `阅读报告.pdf`，放入原文 PDF。
2. 在元数据表加两行（标签先留空可以跑，但建议填完）。
3. 跑**全量**命令。卡片、分类表、索引一起更新。

### 只改标签 / 补一列信息

跑 `--classify-only`：不读 LaTeX、不复制 PDF，几秒完成，适合反复调标签。

### 换研究方向

1. 重写 `tools/taxonomy.csv` 与 `obsidian/标签词表.md`（两份都要改：前者给脚本，后者给人看）。
2. 元数据表里的标签列换新词。
3. `--classify-only` 重跑。

分类表里「旧方向」的分组会自动消失（没有论文命中），历史卡片仍然保留旧标签路径。

### 换目录布局（例如沿用某个已有的项目结构）

```bash
--tex-pattern "paperSearch{b:02d}-{i}/document.tex" \
--pdf-original ""            # 原 PDF 在别的批次目录里，交给 --pdf-original 模板
--pdf-report "{b:02d}-{i}/document.pdf"
```

## 五、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `[warn] 缺少 LaTeX 源` | 报告路径与 `--tex-pattern` 不符；检查目录名是 `3-1` 还是 `03-1` |
| 卡片某小节是「（待补充）」 | `document.tex` 里缺该 `\section`，或标题被改过（标题必须与 `CARD_SECTIONS` 一致） |
| 卡片里公式没渲染 | 数学环境里有中文；看脚本的 `[warn] 公式内出现中文` 提示 |
| 卡片里出现「如 所示」 | 原文用了 `\cref{}`，引用被移除；回 LaTeX 把残句改掉 |
| 分类表某标签篇数为 0 | 数据里没人用该标签；这是词表里有、但还没论文命中的正常现象（该节会被跳过） |
| Obsidian 里「同类论文」为空 | Dataview 插件没启用，或 `--cards-dir` 与查询里的 `FROM` 不一致 |
| Excel 打开 CSV 是乱码 | 用「CSV UTF-8」另存；脚本读的是 `utf-8-sig`，兼容带 BOM |
| 中文路径报错 | Windows 上用引号包住路径，或改用正斜杠 `/` |

## 六、想扩展的话

脚本结构是按「可替换的单点」组织的，扩展时只改一个地方：

| 想改的东西 | 改哪里 |
| --- | --- |
| 报告章节 → 卡片小节的映射 | 文件顶部的 `CARD_SECTIONS` |
| 卡片正文的排版 | `build_card()` |
| 总索引/分类表的排版 | `build_index()` / `build_taxonomy()` |
| LaTeX 清洗规则 | `latex_to_md()` 与 `protect_math()` |
| 词表轴 | `read_taxonomy()` / `check_tags()` 里的 `("种类","挑战","技术")` |
| 新增一种元数据列 | `META_COLUMNS` + 写卡片处用 `row["新列名"]` |

改完建议先用仓库自带的示例数据验证：

```bash
python3 tools/build_cards.py --meta tools/metadata.example.csv --vault ./_build \
    --cards-dir 论文卡片 --index-dir . --classify-only
```

## 七、批量重命名报告目录（可选小工具）

历史报告目录命名不统一时，用一段 shell 对齐到 `批次-序号`：

```bash
cd reports
for d in paperSearch*; do
  new=$(echo "$d" | sed -E 's/paperSearch0*([0-9]+)-(.*)/\1-\2/'); echo "$d -> $new"; mv "$d" "$new"
done
```
