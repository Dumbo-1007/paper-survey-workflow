# LaTeX 报告 → Obsidian 卡片 转换规范

归档脚本 `tools/build_cards.py` 负责把 `document.tex` 的正文抽出来，
清洗成 Obsidian 能正确渲染的 Markdown。本文件说明**转换后的行为**，
以及为了让转换结果正确，你在写 LaTeX 时就该遵守的规则。

## 一、转换原则

| 内容 | 处理 | 原因 |
| --- | --- | --- |
| 正文文字 | 保留 | 卡片的全部价值 |
| 各级标题 | 转为加粗小标题（`**…**`） | 卡片只用二级标题分节 |
| 公式 | 转为 `$…$` / `$$…$$`（MathJax 兼容形式） | Obsidian 用 MathJax 渲染 |
| 列表 | 转为 Markdown 列表 | 保留原文结构 |
| 图片 / 表格环境 | **丢弃** | 图和表不随卡片携带，要看直接翻 PDF 报告 |
| 交叉引用（`\cref` `\ref` `\cite`） | **丢弃** | 卡片内没有编号体系 |
| 注释 `%` | 丢弃 | 本来就是给自己看的 |

> 图与表被丢弃，所以**报告正文的结论必须写成「不依赖图片也能读懂」**。
> 不要出现「如 Fig. 3 所示，本文方法更好」这种只靠图站的句子——转成卡片后会变成一句空话。

## 二、环境与命令映射表

| LaTeX 写法 | 转换结果 | 说明 |
| --- | --- | --- |
| `\[ … \]` | `$$ … $$` | 独立公式 |
| `\( … \)` | `$ … $` | 行内公式 |
| `equation` / `equation*` | `$$\displaylines{ … }$$` | `&` 被去掉 |
| `align` / `gather` / `eqnarray` | `$$\displaylines{ … }$$` | 同上 |
| `aligned` / `gathered` | `\displaylines{ … }` | Obsidian 里 `aligned` 渲染不稳定 |
| `cases` / `array` | 原样保留 | 内部 `&` 与 `\\` 需要保护，脚本已特殊处理 |
| `\tag{5}` / `\eqno` | `\qquad (5)` | MathJax 不认 `\tag` 的编号体系 |
| `\boldsymbol{x}` | `\mathbf{x}` | `\boldsymbol` 需要额外宏包 |
| `\nonumber` / `\notag` / `\label{}` | 删除 | 卡片里没有编号引用 |
| `itemize` / `enumerate` | `- ` / `1. ` 列表 | 每项独立成行 |
| `\section{…}` `\subsection{…}` | `**标题**` | 不含标题层级 |
| `\textbf{}` 等格式命令 | 保留内容 | — |
| `figure` / `table` 环境 | 删除 | 含图注 |

## 三、硬约束：数学环境内不能出现中文

**这是最容易踩、也最容易被忽略的一条。**

```latex
% 错误
s_n = 1 - \frac{\text{簇内像素特征方差}}{\text{参考图像同类像素特征全局方差}}

% 正确
s_n = 1 - \frac{\text{intra-cluster variance}}{\text{global in-class variance}}
```

原因：Obsidian 用 MathJax 渲染 `$…$`，MathJax 的字体与解析规则按数学模式处理，
中文混进去会出现三种后果——字形被拆错、公式整块不渲染、或者行内公式把后面的正文一起吞掉。
中文应该放在数学环境**外面**：

```latex
% 也可以这样做：中文写在公式外
其中 $s_n \in [0,1]$ 表示第 $n$ 个锚点的聚类置信度。
```

脚本会自动检查并提示：

```
[warn] 03-1：公式内出现中文，建议改写成 \text{english}（1 处）
        $$ s_n = 1 - \frac{\text{簇内像素特征方差}}{...} $$
```

如果某些中文确实必须留在 `\text{}` 里（例如集合名），可以用替换表批量处理：
`tools/math_replacements.csv` 两列 `原文,替换为`，脚本在转换末尾按顺序替换。
**替换表是临时补丁，正确的做法是回 LaTeX 直接改。**

## 四、其他 MathJax 兼容性注意点

- 避免 `\substack`、`\binom`、`\gather`、`\gathered`、`\boldsymbol` 这类扩展命令；
  用 `\frac`、`\sum`、`\left\| \right\|`、`\top`、`\odot`、`\mathbb`、`\mathcal`、`\mathrm`。
- 不要用 Unicode 上下标（`Vₘ`、`x²`），一律 LaTeX（`$V_m$`、`$x^2$`）。
- 不要把 `$$` 写成 `$$ ... $$` 单行内联形式再混排中文，独立公式请单独成行。
- `\cref{}` 消失后，句子里的「如 a 所示」这种残句要自己顺手删掉（脚本会留下
  「如 所示」这样的痕迹，属于有意为之——它提示你这里有交叉引用）。

## 五、转换后自检

重跑脚本后，在 Obsidian 里打开新卡片，检查：

- [ ] 所有 `$$` 块都渲染成公式（不是显示成源码）
- [ ] 公式里没有红字或断裂的中文
- [ ] 列表项没有粘连成一段
- [ ] 每个公式后面的符号说明还在（没有被误删）
- [ ] 标题层级正确：`##` 是卡片小节，`**…**` 是原来的子标题

## 六、为什么要做自动转换，而不是手抄

- 手抄一遍 5000 字，等于把 5 小时的阅读成本再翻一倍，而且一定会抄错数字。
- 报告是**唯一手写源**：报告改动 → 重跑脚本 → 卡片同步。手改卡片会在下次重跑时丢失。
- 转换规则固定后，格式问题只需解决一次；论文越攒越多，收益越明显。
