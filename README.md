# 文献调研汇报工作流

> 一套可以照着做的**论文调研范式**：选论文 → 写 LaTeX 阅读报告 → 自动归档成 Obsidian 论文卡片库 → 按研究问题分类复用。
> 目标是让「读完 30 篇论文」不再是一堆散落的 PDF，而是一个**能检索、能对比、能长出选题**的知识库。

---

## 一、这套东西解决什么问题

| 痛点 | 后果 | 本范式的解法 |
| --- | --- | --- |
| 读完就忘，几个月后只剩标题 | 等于白读 | 卡片固定保留「研究问题 / 动机 / 方法要点 / 实验 / **自评**」，半年后 3 分钟回忆全文 |
| 每次汇报格式重来一遍 | 时间浪费在排版 | LaTeX 模板固定 8 节，只填内容 |
| 读了很多篇，说不出领域全貌 | 汇报时讲不出「别人做到哪了」 | 三轴标签 + 分类总表，把论文变成可检索的结构 |
| 找不到同类论文做对比 | 判断不了自己的工作新不新 | 点一下标签，全库同类论文自动并列 |
| 灵光一现的改进想法丢了 | 开题时想不起来 | 自评一节强制把想法写到**公式级** |

## 二、四个核心设计

### 1. 报告结构有 8 节

`阅读文献来源 / 论文待研究科学问题 / 作者研究动机 / 论文工作的主要内容 / 实验数据与评估指标 / 实验结果 / 作者工作评价 / 自己对该论文的评价`

### 2. 三轴标签：一个检索入口不够用

每篇论文打三类标签：

| 轴 | 回答 | 例子 |
| --- | --- | --- |
| `种类/…` | 做的是**哪类任务** | `种类/医学图像分割` |
| `挑战/…` | 主攻**哪个难点** | `挑战/不确定性建模` |
| `技术/…` | 实际用了**什么技术** | `技术/对比学习` |
词表是**闭集**，见 [`obsidian/标签词表.md`](obsidian/标签词表.md)。

### 3. 报告是唯一手写源，卡片是生成物

```
reports/03-1/document.tex   ─┐
                             ├─► tools/build_cards.py ─► 论文卡片 / 分类表 / 总索引（全自动）
tools/metadata.csv          ─┘
```

报告改了 → 重跑脚本 → 卡片同步。**永远不要手改卡片**，否则下次重跑就覆盖了。
好处是：复习时只读卡片（快），维护时只改报告（单一来源，不会出现两个版本不一致）。

### 4. 关键词只存一处

标签只写在 `tags` 里，属性只放标量（题目、年份、分区）

## 四、快速开始

### 0. 依赖

- **Obsidian** + 插件 **Dataview**
- **TeX Live / MiKTeX**（提供 `ctex` 宏包与中文字体），用 `xelatex` 编译
- **Python 3.7+**（只用于归档脚本，无需 pip 安装任何包）
### 1. 用示例数据先跑一遍（1 分钟）

```bash
git clone <this-repo> && cd paper-survey-workflow

python3 tools/build_cards.py \
    --meta examples/元数据示例-30篇.csv \
    --vault ./_build \
    --cards-dir 论文卡片 --index-dir . \
    --classify-only
```

仓库里的 [`examples/分类表示例.md`](examples/分类表示例.md) 是效果演示
### 2. 搭 LaTeX 报告

```bash
mkdir -p reports/01-1/pic
cp latex/document.tex reports/01-1/
```

按 [`docs/02-阅读报告写作规范.md`](docs/02-阅读报告写作规范.md) 逐节填写，
然后编译：

```bash
cd reports/01-1 && xelatex document.tex && xelatex document.tex
```

### 3. 填元数据表

复制一份模板：

```bash
cp tools/metadata.example.csv reports/metadata.csv
```

用 Excel / WPS 编辑（另存为 **CSV UTF-8**），一行一篇，
标签列多个用 `;` 分隔。字段说明见
[`docs/06-自动化与脚本使用.md`](docs/06-自动化与脚本使用.md#一输入的三样东西)。

### 4. 归档

```bash
python3 tools/build_cards.py \
    --meta reports/metadata.csv \
    --src  reports \
    --vault "/path/to/你的Obsidian仓库" \
    --cards-dir "30-研究论文/调研汇报论文库/论文卡片" \
    --index-dir "30-研究论文/调研汇报论文库" \
    --attach-dir "90-附件/调研汇报论文库"
```

调标签改元数据表，加 `--classify-only`。

## 六、换一个研究方向怎么用

这套范式的领域无关，只有两处示例值需要你替换：

| 要替换的东西                    | 文件                                                |
| ------------------------- | ------------------------------------------------- |
| 三轴标签词表（`种类/挑战/技术` 的具体取值）  | `tools/taxonomy.csv` + `obsidian/标签词表.md`         |
| 卡片/表格里展示的元数据列（如 `分区` 的含义） | `tools/metadata.example.csv` 的表头 + `docs/03` 的字段表 |

脚本、模板、Obsidian 查询都不用改。仓库自带的词表是按**医学影像 / 脑疾病分析**方向写的，
直接换方向时，把 `taxonomy.csv` 里三组词换成自己领域的概念即可
（例如 NLP 方向：`种类/文本分类`、`挑战/长尾分布`、`技术/指令微调`）。
